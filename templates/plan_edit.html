A Zerto recovery plan runs its blocks in order when a failover (or failover test) of the plan is started. Put the VPGs that must come up first in tier 1 - typically domain controllers and DNS - then databases, then applications, then everything else. After each tier the plan can wait until that tier's recovery has finished, run a script from the ZVM's script repository, and pause for some minutes. The plan is kept on the ZVM of the site the VPGs recover to. Saving it changes nothing that's running.
